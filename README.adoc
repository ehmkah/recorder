=== Developing

* General information can be found in https://packaging.python.org/en/latest/guides/installing-using-pip-and-virtual-environments/[offical python documentation]

* create python venv `python3 -m venv .venv`
* open environment - `source .venv/bin/activate`
* install dependencies - `python3 -m pip install -r requirements.txt`
